# V19 — Wizard Master + Graveyard

- New Project is now a guided four-step wizard led by a pixel Wizard, the Master of the Project Lab.
- The same Wizard now owns Decide For Me, with a mystical purple oracle panel and mode-specific dialogue.
- Spark/obsession score removed from project metadata and editing.
- Mess replaced by Setup: Grab & Go, Light Setup, Workstation, Take Over the Room.
- Added Project Graveyard: deliberately abandoned projects move to a graveyard shelf and can be resurrected.
- Resurrect mode now chooses from the actual Graveyard.
- Added 14-day cobweb behavior for projects with local last-touched timestamps; touching/session activity clears the neglect clock.
- Added many more distinct panel colors: seafoam, lavender, kelp, midnight, jellyfish purple, sea glass.
- Added ocean-animal choices to the project symbol picker.
- Project Lab is darker/deeper, while Wizard areas use mystical purples.
- Home removes 01/02/03/04 numbering, removes the unused shell/circle cursor options, restores the heart hover treatment, and compacts all four treasure cards into a no-scroll 2x2 landscape layout.
- Home hover scenes are constrained to the bottom-right and use a subtle whole-card texture change instead of large shapes across the content.
