# V18 — Readable Living Archive
- Replaced the app-wide hard-to-read pixel typography with offline-safe Trebuchet/Verdana/Arial system fonts. Pixel-art identity now comes from art, borders, icons and motion rather than illegible body text.
- Enlarged and clarified Pearl Pocket branding.
- Expanded Cursor Companion dock and made hover labels larger/overflow-safe.
- Project Category is now a dropdown; Pixel Symbol is a separate dropdown and can be chosen independently.
- Project cards/details use the selected symbol.
- Treasure-card hover now changes the whole card environment, with stronger module-specific scenes. Encyclopedia opens a larger chest with bubbles/pearl; Creature Index gains creature peeks, trail and sea-grass habitat.
- Rebuilt boot animation as a perspective wave approaching the viewer, with Otter growing toward the screen and a foam wash transition.
